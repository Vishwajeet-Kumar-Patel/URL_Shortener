**New Endpoints:**

**Modified Endpoints:**
- `POST /api/urls/public` - Now accepts referralCode parameter

**Redirect Flow:**
- Updated `/r/:shortCode` to detect `?ref=CODE` parameter
- Creates anonymous session + funnel session for referral links
- Falls back to direct redirect for non-referral links

#### 4. Database Design

**AnonymousSession Model**
- Tracks user → member attribution
- TTL-based auto-expiration (30 min)
- Sparse index on memberId

**RedirectSession Model**
- Multi-step funnel progression tracking
- Step timings with entry/validation timestamps
- TTL-based auto-expiration (10 min)
- Nested FunnelStepTiming subdocuments

**MemberMetrics Model**
- Denormalized for fast dashboard queries
- Atomic increment operations
- Fields: totalUsers, totalLinks, totalClicks, earnings

#### 5. Service Layer

**AnonSessionService** (95 lines)
- Create sessions with referral attribution
- Resolve referral codes to members
- Track link generation
- Return member statistics

**FunnelValidationService** (130 lines)
- Validate step progression
- Return progress information
- Mark sessions as qualified

**PayoutAutomationService** (155 lines)

## Architecture Highlights

### Three-Layer Monetization System

```
User Joins via Referral Code
    ↓
Creates Anonymous Session (AnonSessionService)
    ↓
Generates Short URL (with referralCode parameter)
    ↓
Shares Link
    ↓
Click: Creates Redirect Session (FunnelValidationService)
    ↓
Steps 1-4: Progressive Validation
    ↓
Step 5: Mark as Qualified
    ↓
Payout: CPM Calculation → Wallet Credit (PayoutAutomationService)
    ↓
Referrer Earned Money 💰
```

### Real-Time Funnel Tracking

Each step provides real-time feedback:
- **Progress percentage** updated on API calls
- **Scroll percentage** tracked client-side
- **Step completion** validated server-side
- **Validation messages** returned immediately

### Anti-Bypass Features

- **Step 2:** Server-side scroll validation (can't be bypassed by API manipulation)
- **Step 4:** Quiz answers must match expected values
- **Timing:** Session expires after 10 minutes
- **Qualification:** Marked only when all steps completed
