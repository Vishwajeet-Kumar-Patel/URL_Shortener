# Phase 1 Implementation: Funnel Monetization System

## Overview

This document describes the Phase 1 implementation of the PurpleMerit Links monetization system, which enables creators to earn CPM from qualified traffic through a multi-step funnel.

## System Architecture

### Three-Layer Flow

1. **Anonymous Session Layer** - Tracks anonymous users and their member referrer
2. **Funnel Validation Layer** - Manages 5-step progression with validation rules
3. **Payout Automation Layer** - Calculates and credits earnings to wallets

### New Database Models

#### `AnonymousSession`
- Tracks anonymous user sessions with referral attribution
- Fields: sessionToken, memberId (sparse), referralCode, ipHash, isValid, expiresAt
- TTL: 30 minutes auto-expiration
- Used by: AnonSessionService

#### `RedirectSession`
- Tracks multi-step funnel progression
- Fields: currentStep (1-5), completedSteps, scrollPosition, ctaClicked, isQualified
- Contains: FunnelStepTiming subdocuments with step entry/validation times
- TTL: 10 minutes auto-expiration
- Used by: FunnelValidationService, PayoutAutomationService

#### `MemberMetrics`
- Denormalized performance metrics for dashboard queries
- Fields: totalAnonymousUsersBrought, totalAnonymousLinksGenerated, totalQualifiedClicks, totalEarnings, thisMonthEarnings, thisMonthUsers
- Unique index: memberId
- Used by: Member earnings tracking

#### `ShortUrl` (Modified)
- Added: createdByMemberId (sparse, indexed)
- Added: anonymousSessionId (sparse, indexed)
- Used for: Attribution of anonymous-generated links to members

## Frontend Features

### 1. Anonymous Homepage (Public)

**Route:** `/` (Homepage)  
**Components:**
- Anonymous URL shortening form (no login required)
- Optional referral code input
- Share buttons for generated short URLs
- Monetization explanation section

**User Flow:**
1. User enters URL without logging in
2. Optionally enters referral code
3. Gets short URL immediately
4. Can share via social/copy link

**Backend Integration:**
- POST `/api/urls/public` - Creates short URL with optional referralCode

### 2. Multi-Step Funnel Pages

**Primary Route:** `/funnel/[sessionId]` (Router to appropriate step)

#### Step 1: Blog/Article Discovery
**Route:** `/funnel/step-1/[sessionId]`
- Displays blog content with ads
- Explains value of content
- Button: "Continue to Next Step"
- No validation required

#### Step 2: Scroll Unlock
**Route:** `/funnel/step-2/[sessionId]`
- Long-form article content
- Real-time scroll percentage tracking
- **Requirement:** 80%+ scroll to unlock
- Locked button until threshold met
- On unlock: Advances to Step 3

#### Step 3: Sponsored Ad/CTA Click
**Route:** `/funnel/step-3/[sessionId]`
- Promotional offer card
- "Claim Your Offer" CTA button
- **Requirement:** CTA click tracking
- On click: Advances to Step 4

#### Step 4: Reward Verification (Quiz)
**Route:** `/funnel/step-4/[sessionId]`
- 3-question quiz based on previous content
- Tests attention to content
- **Requirement:** All answers correct
- Navigation: Previous/Next buttons
- On pass: Advances to Step 5

#### Step 5: Final Unlock & Redirect
**Route:** `/funnel/step-5/[sessionId]`
- Celebration screen with progress indicator (100%)
- Summary of completed steps
- Earnings explanation for creator
- "Unlock & Access Content" button
- On click: Redirects to target URL via window.location.href

### 3. Partner Dashboard

**Base Route:** `/dashboard/partner/`

#### Referral Link Page
**Route:** `/dashboard/partner/referral-link`
- Display unique referral code
- Copy referral code button
- Referral URL with ref parameter
- Social share buttons (Facebook, Twitter, Email, WhatsApp)
- Stats display:
  - Total Users Brought
  - Links Generated by Referrals
  - This Month Users
- Navigation to other partner pages

#### Anonymous Links Page
**Route:** `/dashboard/partner/anonymous-links`
- List of links generated by referred users
- Columns: Short URL, Original URL, Created Date, Total Clicks, Qualified Clicks
- Copy URL functionality
- Link to referral page

#### Earnings Page
**Route:** `/dashboard/partner/earnings`
- Summary cards:
  - Total Earnings
  - This Month Earnings
  - Qualified Clicks
- Breakdown table by country:
  - Country | Clicks | Earnings
- Request withdrawal button
- Link to withdrawal page

#### Withdrawal Page
**Route:** `/dashboard/partner/withdrawal`
- Balance cards:
  - Available Balance (ready to withdraw)
  - Pending Balance (processing)
- Withdrawal form:
  - Amount input (with max validation)
  - Bank account selector
  - Submit button
- Withdrawal history:
  - Amount | Date | Status (Pending/Approved/Rejected/Completed)
- Link back to referral page

## Backend API Routes

### Redirect Module Routes

#### 1. Resolve Short Code
**Endpoint:** `GET /api/redirect/resolve/:shortCode`  
**Auth:** None (rate-limited)  
**Response:**
```json
{
  "success": true,
  "data": {
    "shortCode": "abc123",
    "targetUrl": "https://example.com"
  }
}
```

#### 2. Start Visit (Legacy Ad Session)
**Endpoint:** `POST /api/redirect/visit/:shortCode`  
**Auth:** None (rate-limited)  
**Body:**
```json
{
  "jsEnabled": true,
  "cookiesEnabled": true
}
```
**Response:**
```json
{
  "success": true,
  "data": {
    "sessionId": "hex-string",
    "continueAfterSeconds": 5
  }
}
```

#### 3. Complete Visit (Legacy)
**Endpoint:** `POST /api/redirect/complete/:sessionId`  
**Auth:** None (rate-limited)  
**Response:**
```json
{
  "success": true,
  "data": {
    "redirectUrl": "https://target-url.com"
  }
}
```

#### 4. Validate Funnel Step (NEW)
**Endpoint:** `POST /api/redirect/funnel/validate-step/:sessionId`  
**Auth:** None (rate-limited)  
**Body:**
```json
{
  "currentStep": 2,
  "scrollPosition": 85,
  "viewportHeight": 800,
  "ctaClicked": false,
  "hasScrolledEnough": true
}
```
**Response:**
```json
{
  "success": true,
  "data": {
    "isValid": true,
    "nextStep": 3,
    "message": "Step validated. Please proceed to next step."
  }
}
```

#### 5. Get Funnel Progress (NEW)
**Endpoint:** `GET /api/redirect/funnel/progress/:sessionId`  
**Auth:** None (rate-limited)  
**Response:**
```json
{
  "success": true,
  "data": {
    "currentStep": 2,
    "completedSteps": [1, 2],
    "progress": 40,
    "shortCode": "abc123"
  }
}
```

## Service Implementations

### AnonSessionService
**Location:** `/modules/redirect/anon-session.service.ts`

**Key Methods:**
- `createSession(userAgent, ipHash, referralCode?)` → Returns sessionToken + memberId
- `getSession(sessionToken)` → Retrieves session data
- `getMemberStats(memberId)` → Returns user/link counts
- `trackLinkGeneration(sessionToken, memberId?)` → Increments counters

**Integration Points:**
- ReferralRepository (resolve referral codes)
- MemberMetricsRepository (track stats)
- AnonymousSessionRepository (CRUD)

### FunnelValidationService
**Location:** `/modules/redirect/funnel-validation.service.ts`

**Key Methods:**
- `validateAndAdvanceStep(sessionId, currentStep, validationData)` → Returns {isValid, nextStep, message}
- `getSessionStatus(sessionId)` → Returns {isComplete, isQualified, currentStep, targetUrl}
- `getProgress(sessionId)` → Returns progress percentage and completed steps

**Step Validation Rules:**
- Step 1: Always valid (no validation)
- Step 2: Requires scrollPosition >= 80%
- Step 3: Requires ctaClicked = true
- Step 4: Requires all quiz answers correct (handled by frontend)
- Step 5: Final unlock, marks session as qualified

### PayoutAutomationService
**Location:** `/modules/redirect/payout-automation.service.ts`

**Key Methods:**
- `processSessionPayout(sessionId)` → Finds qualified session, applies CPM, credits wallet
- `calculateMemberEarnings(memberId, since?, until?)` → Returns {totalClicks, totalEarnings, byCountry[]}
- `processDailyPayouts()` → Batch job for daily payout processing

**Integration Points:**
- CPMRateRepository (geolocation rates)
- WalletService (credit operation)
- ClickRepository (location data)
- MemberMetricsRepository (update stats)

## Referral Attribution Flow

### When User Joins via Referral Code

1. **Frontend:** User clicks referral link with `?ref=REF_ABC123`
2. **Homepage:** Anonymous URL generator accepts referralCode in form
3. **Backend:** POST /api/urls/public with referralCode
4. **AnonSessionService:** Creates session, resolves code to memberId via ReferralRepository
5. **MemberMetricsRepository:** Increments thisMonthUsers, totalUsersBrought
6. **CreatedUrl:** Links stored with createdByMemberId

### When Referred User Generates Link

1. **Frontend:** User generates short URL (without login, via anon form)
2. **Backend:** URL service creates link with anonymousSessionId
3. **MemberMetricsRepository:** Increments totalLinksGenerated for member
4. **ShortUrl Model:** Records createdByMemberId + anonymousSessionId

### When Link Gets Qualified Click

1. **Frontend:** User completes 5-step funnel
2. **Backend:** Step 5 validation marks session as qualified
3. **PayoutAutomationService:** Finds referring member, calculates CPM based on country
4. **WalletService:** Credits member's wallet with calculated amount
5. **MemberMetricsRepository:** Increments totalQualifiedClicks, totalEarnings, thisMonthEarnings

## Testing Flow (Manual)

### Happy Path: Referral → Monetized Link

1. **Setup:** Create member account via /register
2. **Get Code:** Go to /dashboard/partner/referral-link (copy code)
3. **Share:** Open homepage with ?ref=REF_CODE query param
4. **Create Link:** Use anon form to shorten a URL
5. **View Stats:** /dashboard/partner/anonymous-links shows the created link
6. **Full Funnel:** Visit the short code link:
   - Should redirect to /funnel/[sessionId]
   - Auto-redirects to /funnel/step-1/[sessionId]
   - Step 1: Click "Continue"
   - Step 2: Scroll to 80%, button unlocks
   - Step 3: Click "Claim Your Offer"
   - Step 4: Answer 3 questions (from content), click "Verify"
   - Step 5: Click "Unlock & Access Content" → Redirects to target
7. **Verify Earnings:** /dashboard/partner/earnings shows +1 qualified click + CPM amount

## Database Relationships

```
User
├── AnonymousSession (1:many via memberId)
├── ShortUrl (1:many via ownerId)
├── MemberMetrics (1:1 via memberId)
└── Referral (1:many)

Referral
└── AnonymousSession (1:many via referralCode resolution)

ShortUrl
├── AnonymousSession (via anonymousSessionId)
├── RedirectSession (1:many via shortCode)
└── ClickLog (1:many)

RedirectSession
├── AnonymousSession (1:1 via anonymousSessionId)
└── CPMRate (calculated from country/user-agent)

MemberMetrics
└── Updated by: AnonSessionService, PayoutAutomationService
```
